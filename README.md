# Rio–Antirrio AI Assistant

## Τεχνικό Εγχειρίδιο – Οδηγός Συντήρησης & Παράδοσης

Το repository αυτό περιέχει τα εξωτερικά αρχεία του **Rio–Antirrio AI Assistant**, του τοπικού βοηθού για τη γραμμή πορθμείων Ρίου–Αντιρρίου.

Το παρόν `README.md` αποτελεί το βασικό τεχνικό εγχειρίδιο του project.

Σκοπός του είναι οποιοσδήποτε αναλάβει το project στο μέλλον — ο δημιουργός του, άλλος προγραμματιστής ή άλλο AI/νέα συνομιλία — να μπορεί να καταλάβει:

- τι έχει ήδη ολοκληρωθεί,
- ποια αρχεία χρησιμοποιούνται,
- ποιο αρχείο είναι υπεύθυνο για κάθε λειτουργία,
- πώς προσθέτουμε νέες ερωτήσεις,
- πώς αλλάζουμε απαντήσεις,
- πώς κάνουμε αλλαγές χωρίς να καταστρέφουμε λειτουργίες που ήδη δουλεύουν,
- και πώς μπορούμε να επιστρέψουμε σε ασφαλές σημείο αν κάτι πάει στραβά.

# 8. phrases, keywords και requiredAny

Κάθε intent μπορεί να χρησιμοποιεί:

phrases: [...]
keywords: [...]
requiredAny: [...]

## phrases

Χρησιμοποιούνται για φυσικές φράσεις/ερωτήσεις που μπορεί να γράψει ο χρήστης.

Παράδειγμα:

πότε έχει το επόμενο καράβι

## keywords

Λέξεις που βοηθούν τον μηχανισμό βαθμολόγησης και αναγνώρισης του intent.

## requiredAny

Χρησιμοποιείται όταν απαιτείται να υπάρχει τουλάχιστον μία από συγκεκριμένες λέξεις ώστε να θεωρηθεί έγκυρη η αντιστοίχιση.

### Προσοχή

Δεν προσθέτουμε την ίδια φράση ανεξέλεγκτα σε πολλά intents.

Αυτό μπορεί να προκαλέσει **intent collision**, δηλαδή να επιλέγεται λάθος κατηγορία.

# 9. Διαδικασία προσθήκης ερώτησης

Πριν προστεθεί νέα ερώτηση:

1. Ελέγχουμε αν υπάρχει ήδη ίδια ή παρόμοια φράση.
2. Βρίσκουμε το σωστό intent.
3. Αποφεύγουμε διπλοεγγραφές.
4. Προσθέτουμε την ελληνική μορφή.
5. Προσθέτουμε χρήσιμη Greeklish μορφή όπου χρειάζεται.
6. Ελέγχουμε αν απαιτείται keyword.
7. Ελέγχουμε αν απαιτείται `requiredAny`.
8. Δοκιμάζουμε τη νέα ερώτηση.
9. Δοκιμάζουμε και παλιές σχετικές ερωτήσεις ώστε να βεβαιωθούμε ότι δεν δημιουργήθηκε σύγκρουση.

# 13. Σύνδεση Engine με Knowledge

Ο εξωτερικός Engine **δεν περιέχει πλέον ολόκληρο το inline INTENTS catalogue**.

Αντί γι’ αυτό χρησιμοποιεί:

const INTENTS = (
    window.RioAIKnowledge &&
    window.RioAIKnowledge.intents
);

Υπάρχει επίσης προστασία ώστε ο Engine να μην ξεκινήσει σιωπηλά αν δεν έχει φορτωθεί το Knowledge.

Αυτό δημιουργεί μία πολύ σημαντική εξάρτηση:

> **Το Knowledge πρέπει να φορτώνεται πριν από τον Engine.**

# 19. Κατάσταση γραμμής

Ερωτήσεις όπως:

δουλεύουν τα καράβια;
εκτελούνται δρομολόγια;

υπάρχει απαγορευτικό;

window.ferryAlertMessage

όπου υπάρχει.
